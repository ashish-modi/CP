# CP

Competitive programming solutions, algorithm implementations, and data structure references, organized by source and topic.

## Repository Structure

| Folder | Contents |
|---|---|
| [`Algos`](./Algos) | Standalone implementations of core algorithms and data structures for reuse across problems |
| [`Codeforces`](./Codeforces) | Solutions to Codeforces problems |
| [`Dynamic Programming`](./Dynamic%20Programming) | DP problems and patterns (memoization, tabulation, classic DP templates) |
| [`GeeksForGeeks`](./GeeksForGeeks) | Solutions to GeeksForGeeks practice problems |
| [`Graphs`](./Graphs) | Graph algorithms and related problems (traversal, shortest paths, connectivity, etc.) |
| [`Leetcode`](./Leetcode) | Solutions to LeetCode problems |
| [`Tips`](./Tips) | Notes, tricks, and problem-solving techniques for competitive programming |
| [`codes`](./codes) | Miscellaneous/general-purpose code snippets |

## Purpose

This repository serves as a personal archive and reference of:
- Problem solutions from competitive programming platforms (Codeforces, LeetCode, GeeksForGeeks)
- Reusable algorithm and data structure implementations
- Notes and tips collected while practicing problem-solving

## Usage

Browse the relevant folder for a given platform or topic. Each solution file generally corresponds to a specific problem, named to indicate the problem it solves.

To use locally:

```bash
git clone https://github.com/ashish-modi/CP.git
cd CP
```

Then navigate into the topic or platform folder you're interested in.
